# RetainAI Database (`retail.db`)

This directory contains the primary SQLite database (`retail.db`) used by the RetainAI platform. The database serves as the central data store for customer analytics, machine learning predictions, and business intelligence dashboards.

## Database Schema Overview

The database acts as the central hub for both raw historical data and AI-generated insights. It consists of four primary tables:

### 1. `customers`
The core table powering the dashboard. It contains aggregated historical metrics (RFM), behavioral data, and the machine-learning generated predictions for every customer.
* **Key Fields:** `customer_id`, `recency`, `frequency`, `monetary`, `clv`, `churn_probability`, `churn_prediction`, `segment`

### 2. `transactions`
The raw transactional history. This table stores individual purchase events, which are aggregated to generate the customer metrics and used in the Customer 360 view.
* **Key Fields:** `invoice`, `stock_code`, `description`, `quantity`, `unit_price`, `customer_id`, `country`, `total_amount`, `date`

### 3. `predictions`
Reserved for storing prediction history generated by the backend API.

The table is included in the schema to support future persistence of prediction requests. In the current version of RetainAI, prediction history is maintained within the active Streamlit session rather than being permanently written to the database.
* **Key Fields:** `prediction_id`, `customer_id`, `prediction_type`, `prediction`, `confidence`, `created_at`

### 4. `model_metadata`
Stores metadata about the deployed machine learning model, including model version, algorithm, evaluation metrics, and training information. This table is intended to support model tracking and future version management.
* **Key Fields:** `model_name`, `version`, `algorithm`, `accuracy`, `precision`, `recall`, `f1_score`, `roc_auc`

## Database Creation

The `retail.db` SQLite database is generated automatically from the processed datasets included in this project. It is created using the database initialization script located in the `scripts` directory.

To recreate the database from scratch, run:

```bash
python scripts/create_database.py
```

The script performs the following tasks:

- Creates the complete SQLite database schema.
- Creates the `customers`, `transactions`, `predictions`, and `model_metadata` tables.
- Imports customer and transaction data from the processed Parquet datasets.
- Populates the database with all required records for the RetainAI application.
- Safely recreates the database if it already exists, ensuring a clean and consistent state.


### Database Creation Workflow

The following workflow illustrates how the SQLite database is generated from the processed datasets:
```text
Online Retail Dataset
        │
        ▼
Processed Parquet Files
        │
        ▼
create_database.py
        │
        ▼
SQLite (retail.db)
        │
        ├── customers
        ├── transactions
        ├── predictions
        └── model_metadata
```


This script should be executed whenever the processed datasets are updated or when setting up the project on a new machine.

## Version Control

The `retail.db` file is included in this repository to provide a ready-to-run demonstration environment. This allows anyone cloning the project to start the application immediately without recreating the database.

If the processed datasets are updated, the database can be regenerated at any time by running:

```bash
python scripts/create_database.py
```
